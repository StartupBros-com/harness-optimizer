# Operation Compatibility

Resolve the **effective selected installation** before each operation. A cache,
sibling checkout, marketplace version listing or this reference establishes no
callable authority. Read its public entry definition and version; identify its
inputs, outputs, side effects, invocation rule, concrete consent, verification,
recovery and existing continuation state. If one is missing, leave that operation
unsupported and name the missing contract. Recheck version and patch identity
before mutation. Changed contracts require fresh reconciliation and any newly
required approval. Never import undocumented internals or substitute a weaker
apply surface.

For lane assignments, source bounds and common returns, use [lane discovery](discovery.md).
That discovery boundary does not authorize specialist invocation; the effective
operation contracts below remain authoritative.

## Useful without optional plugins

An authorized defect in a selected repository can use the host's ordinary
engineering process: isolate, demonstrate the defect, reconcile proposals,
apply conflict-aware changes, check behavior and regressions, and integrate by
the host's existing review/deployment rules. Record actual revision/digest and
activation separately. This path cannot reproduce protected memory, settings,
portfolio or installation operations under a different label. If safe atomic
application or conflict-aware integration is unavailable, leave mutation
unsupported. When no specialist is present, continue this useful work and name
missing maintenance coverage. Install nothing implicitly.

## Handoff and evidence

A handoff names the selected scope, substantiated problem, concrete proposed
patch/operation, missing direct invocation or post-preview decision, expected
benefit, checks and remaining coverage. Include only relevant non-secret data.
A human refusal leaves that change declined; continue independent work without
retrying it under another component. Existing component state is preferred for
continuation, never a new approval store. Recall probes, fixture runs and source
checks remain labeled as such. Field recurrence needs an observation window and
exposure denominator; unavailable exposure permits only a descriptive count.
